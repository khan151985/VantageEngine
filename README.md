# Vantage Engine - 3D Interactive Digital Twin

Vantage Engine is a powerful, web-based 3D Interactive Digital Twin app builder. It allows users to create immersive, 3D interactive maps and environments for historical, educational, and architectural purposes.



## Features

- **3D Visualization**: Load and interact with GLB/GLTF models.
- **Interactive Points**: Place points of interest with custom content (text, images, video, 360° panoramas).
- **Multilingual Support**: Built-in translation and support for multiple languages.
- **AI Integration**: Enhance and translate content using OpenAI's GPT models.
- **Customization**: Flexible UI themes, measurement tools, and animation paths.
- **Cross-Platform**: Optimized for Desktop and Mobile devices.

## Getting Started

### Prerequisites

- A modern web browser with WebGL support.
- (Optional) An OpenAI API key for AI-powered features.

### Installation

1. Clone or download the repository.
2. Open `index.html` in your web browser.

## Configuration

To use the AI-powered translation and content enhancement features:
1. Open the app.
2. Navigate to **Settings > API Configuration**.
3. Enter your OpenAI API key.

## Architecture

The project is built using:
- **Three.js**: For 3D rendering and scene management.
- **Vanilla JavaScript**: Core application logic and state management.
- **CSS**: Custom styling for a premium dark-themed interface.

## Repository Structure

- `assets/`: UI assets and logos.
- `css/`: Stylesheets for various components.
- `js/`: Application logic (renderers, loaders, state management).
- `index.html`: Main entry point.
